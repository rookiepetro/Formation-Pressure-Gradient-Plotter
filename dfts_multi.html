How to perform Multi-Well Analysis
  1. Enter Name: Type "Well-1" in the Well Name box.
  2. Paste Data: Paste Depth & Pressure for Well-1. Click Add Well. (It appears in a specific color).
  3. Repeat: Type "Well-2", paste data, click Add. (It appears in a DIFFERENT color).
  4. Compare: Visually check if points from Well-1 and Well-2 align.
  5. Draw Gradient: Select points from ANY well in the table to draw a gradient line. This helps identify if different wells share the same aquifer or hydrocarbon leg.
